# Introduction

## About This Guide

Maestro CLI, also known as M3-CLI, is a robust command-line interface (CLI) tool designed to provide a powerful alternative to user interfaces (UI). It allows you to perform cloud infrastructure management operations, as well as manage related assets, by sending respective calls to Maestro cloud management platform. This Reference Guide provides users the overview of the available M3 CLI commands, their purpose, parameters, and usage examples.

## Target Audience

The guide is designed for Maestro users who aim to reach Maestro functionality via a CLI interface.
